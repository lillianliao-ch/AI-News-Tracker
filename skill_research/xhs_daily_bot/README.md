## 🧠 系统组件说明 (核心业务逻辑)

本系统进化出了两条威力巨大的独立流水线：

### 引擎一：每日晨间定时打爆机 — `run_campaign.py`
*（主引擎，负责吃透每日全网科技资讯热榜）*

- **触发机制**：已通过 macOS 底层 `crontab` 唤醒引擎（每天早晨 **08:00** 准点点火）。
- **底料情报员 (Sourcing)**：调用 `opencli` 强行抓取 HackerNews 国际极客热榜，用 `Qwen-Plus` (千问) 根据“前沿技术突破、求职价值、变现逻辑”这三大金纬度给资讯打分，严防死守筛出 Top 5 巅峰硬核内容。
- **分裂撰稿员 (Brain)**：这 5 条硬核源文件，分别被丢入 `A版(高阶宏观商业视角)` 和 `B版(极尽扎心的求职生存指南)` 两个预制 Prompt 发酵舱，1 分钟内为您输出 10 篇结构森严的高完播率 Markdown 笔记。
- **巨物排版师 (Visual)**：经过极限测试并斩断了大模型的绘画依赖（抛弃 Wanx-V1 造成的乱码和抽象）。本系统采用了自主研发的**「大字报·全骨架排版引擎」**，调用操作系统深层的 Apple `Hiragino / Heiti` 黑体字库，采用高强度的抗锯齿描边、极端的左对齐留白与红框徽章系统，一瞬间精准烙印出霸气的纯文字版视觉炸弹。
- **发稿特工 (Publisher)**：生成 10 篇图文后，它会切碎文件包装成特定的命令格式，通过 `opencli xiaohongshu publish` 静默钻进您的创作者平台，把这 10 篇草案依次妥帖摆入库中。

### 引擎二：点名道姓题材狙击机 — `run_topic_campaign.py`
*（子引擎，负责随时针对某个具体的行业事件疯狂出稿）*

- **触发机制**：手动（On-Demand）。
- **核弹头 (Web Search Agent)**：彻底斩断了被动的 HackerNews 推流，直接调用了全功率开启 `enable_search=True` (实时全网搜索) 的 `Qwen-Plus` 探针！只需要您抛出一个关键词（如：`Apple AI` / `Vibe Coding` / `月之暗面算力池`），这根探针会自动游荡在当天的互联网沙海里，为您归纳、拆分并生造出关于该主题的 **5 个顶级爆点视角**！
- **完美复用 (Pipeline)**：拿到这 5 个视角底本后，由于架构的一致性极高，它会天缝衔接、100% 复用上面那套**完美的高级撰稿员与大厂风 UI 渲染师**产线，同样在三分钟内，给您交付 10 篇同一主题但在 10 个不同角度的极品草案！

## 👻 进阶架构剖析：Headless API Token 注入 (静默发稿引擎)

本系统在小红书发稿环节（`@jackwener/opencli`）彻底摒弃了传统的“RPA 可视化屏幕点击（如 Playwright 开界面打字）”，转而采用了工业级的 **Headless（无头静默层）自动化通信**。

### 工作原理 (Cookie / Token 隧道传输)
1. **身份伪装储藏**：在首次扫码配置后，引擎会将创作者平台下发的 `Cookie / Session Token` 永久固化在本地隐藏缓存中。
2. **脱离 UI 渲染的降维打击**：程序运行时不再拉起任何浏览器视窗，不加载任何背景图片与前端 JS 代码。
3. **二进制直连**：引擎直接在终端底层将排版好的 Markdown 文本与生成的 JPG 图片打包为底层 HTTP 网络请求流，夹带身份 Token，通过后台网络栈“硬塞”给小红书的上传服务器。

### 该架构的绝对优势
- **全静默、不抢焦点**：它在发工作台发稿时，您的屏幕焦点完全不受影响，甚至感觉不到它的存在。
- **高并发极速**：跳过了前端页面的 `DOM` 渲染和长达数秒的等待动画，直接与数据库握手，实现秒传。
- **纯正的 CI/CD 基因**：这套逻辑可以脱离 Mac 宿主机，被完美移植到毫无图形界面（GUI）、显卡和屏幕的纯 Linux 云服务器上，实现 24 小时 365 天无感值守。
