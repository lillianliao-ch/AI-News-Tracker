Title: 千问C端事业群-多模态交互SDK开发专家-杭州/上海/深圳

【岗位描述】
1. 设计并实现高性能、低资源占用的多模态交互 SDK 架构，支持语音、视觉（如人脸识别、手势识别）、传感器融合等 AI交付 能力；
2. 开发跨操作系统（RTOS、Linux、Android）的统一 API 接口与平台适配层，确保 SDK 在不同硬件与 OS 环境下的一致性与兼容性；
3. 使用 C++ 实现 SDK 核心引擎（如推理调度、模态融合、状态管理、资源优化），使用 Java/Kotlin 开发 Android 平台绑定与上层接口；
4. 针对 RTOS 和资源受限的嵌入式 Linux 环境，优化内存、CPU 与功耗，实现轻量化部署；
5. 与 AI 算法团队协作，高效集成端侧模型（如 ONNX/TensorFlow Lite/NNAPI），并设计推理调度与缓存策略。

【岗位要求】
1. 计算机科学、软件工程或相关专业本科及以上学历；5年以上系统级软件或 SDK 开发经验，具备扎实的跨平台开发能力；
2. 精通C++ 编程范式、内存管理、并发模型及性能调优；
3. 熟悉 Java/Kotlin，有 Android Native (JNI) 与 Framework 层开发经验；
4. 理解RTOS（如 FreeRTOS、Zephyr、ThreadX）下的任务调度、内存限制、低功耗机制；Android 系统架构、Binder、HAL、NDK 及权限模型；
5. 有实际 SDK 或中间件开发经验，熟悉 API 设计原则、版本管理与向后兼容策略；
6. 熟悉多线程、异步编程、事件驱动架构及 IPC 通信机制；
7. 有语音识别（ASR/TTS）、计算机视觉（CV）、传感器融合或多模态大模型（MLLM）端侧部署经验优先。
