Title: AI Agent 工程师（智能体系统与上下文工程）

【岗位描述】
1. 构建可运行的 Agent：实现 intent 识别/任务分解/规划执行/工具调用/记忆与状态管理/失败恢复等核心链路
2. 端到端负责闭环：问题定义、数据与工具接入、原型实现、线上/线下验证、评估与复盘，输出结论（继续/停止/转向）
3. 设计并实现 Agent Runtime：会话与任务状态机、并发与队列、超时与重试、权限与审计、降级与回滚
4. 与多角色协作：把需求变成可执行的 agent spec，把模型能力变成稳定的系统能力
5. 推动 agent 技术路线图与关键架构决策：工具协议、记忆方案、评测口径、发布与灰度机制

【岗位要求】
1. 本科及以上（计算机/软件工程/AI 相关优先），3 年以上后端/平台/AI 工程经验，或有成熟的 agent/LLM 应用落地经验
2. 熟练掌握至少一门主力语言（Python / Go / Java 等），具备大型项目工程经验
3. 扎实的软件工程能力：架构设计、可靠性、可观测、性能与成本优化、可维护性
4. 有“从 0 到可验证”的完整交付经验：能把探索做成可运行系统，并用评测/数据输出结论
5. 良好的跨团队协作与表达能力：能清晰描述权衡、边界与风险
加分项

- 做过 RAG/知识库工程：索引、召回、重排、缓存、增量更新、评测与可观测
- 熟悉 多模态 Agent（图像/语音/视频）或在内容/搜索/推荐场景做过 agent 化探索
