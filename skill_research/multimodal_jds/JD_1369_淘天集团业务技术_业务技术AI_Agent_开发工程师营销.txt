Company: 淘天集团-业务技术
Title: 业务技术-AI Agent 开发工程师-营销前台

【岗位描述】
1、负责淘天集团核心电商的营销业务，包括但不限于：超大型营销活动导购、优惠/红包/互动玩法等，参与或主导营销业务的AI应用，运用AI思维与工程手段，主动探索创新性解决方案，为业务带来突破性变化；
2、参与构建AI驱动的营销前端工程体系，深入LLM、多模态、Agent系统在前端开发中的结合应用，设计并实现AI能力在前端架构的集成落地，包括但不限于D2C、AI Coding、自动化测试等；
3、负责 Agent 关键基础能力建设，包括 Prompt 工程、上下文工程、知识库/RAG、记忆机制、工具系统、评测体系、监控与可观测性建设等。
4、结合业务数据与用户反馈，持续进行效果优化，提升 Agent 的任务成功率、准确率、稳定性、时延表现与用户体验。

【岗位要求】
【基础要求】
● 本科及以上学历，计算机、人工智能、机器学习、自然语言处理等相关专业优先。
● 熟悉 LLM、Prompt、Embedding、RAG、Function Calling、Workflow 等基础概念，并具备实际项目经验。
● 具备 Agent 应用开发经验，能够基于业务目标完成基础任务拆解、流程编排、工具接入与结果生成。
● 了解知识库/RAG 的基本链路，包括知识接入、切分、索引、召回、生成等关键环节，并有一定实践经验。

【核心要求】
● 具备较强的 AI Native 思维，能够围绕模型能力、任务目标、数据反馈与效果闭环设计系统，而非仅停留在 API 接入或简单应用集成层面；具备 复杂 Agent 系统开发经验，理解并实践过 ReAct、Plan-and-Execute、Tool Use、Multi-Agent 等常见模式，能够独立完成任务链路设计、工具编排与工程落地。
● 对 上下文工程 有较深入理解，能够通过上下文裁剪、结构化记忆、摘要、检索增强、动态装配等方式提升复杂任务处理效果。
● 对 知识库 / RAG 有系统性理解与实战经验，能够完成知识接入、切分、索引、召回、重排、生成、评测和线上优化等完整链路建设。
● 具备 Agent 评测与调优能力，能够围绕业务目标构建评测集、定义评测指标，持续优化 Prompt、Workflow、检索策略、工具调用与结果生成质量；具备一定模型后训练与调优能力，理解 SFT、LoRA/QLoRA、偏好优化、训练数据构造等方法，并能在具体业务中参与效果优化。

【加分项】
● 有 AI Agent 应用的规模化落地经验和代表产品优先，
● 有模型调优、训练数据构建、推理部署、模型服务治理或线上稳定性建设经验者优先；
