### 三、 技术攻坚方向窥探：MiniMax 正在押注什么？

根据过去半年这些核心成员的“项目经历”，我们发现 MiniMax 
的技术重心正在发生显著偏移：

1.  **“01 架构”的全面迭代**：
    频繁出现的 **Minimax 01** 架构代号 [5, 
8]，预示着公司正在抛弃旧有的 Transformer 
变体，转向更高效的线性复杂度或混合架构（如 **Lighting 
Attention**），以应对超长文本（10M+）的需求 [5, 12]。

2.  **强化学习从“偏好对齐”转向“推理增强”**：
    不再仅仅是简单的 SFT。项目经历中出现了 **HER (Human-like 
Reasoning)**、**MCTS (蒙特卡洛树搜索)** 以及 **Tool-RL** [12, 14, 
37]。这表明 MiniMax 正在对标 OpenAI o1，通过 RL 
提升模型的逻辑思考能力和复杂任务拆解能力。

3.  **多模态的“物理世界模拟”**：
    海螺视频的研发重心集中在 **Wan2.2-I2V**、**ID 一致性优化**及 
**物理世界理解** 
[38]。他们在攻坚如何让视频生成不只是“拼凑画面”，而是具备连贯的动作
逻辑和身份稳定性。

4.  **极致的推理成本控制 (PD 分离)**：
    工程团队在强推 **PD (Prefill/Decoding) 分离架构** 
[4]。通过计算与存储的分离，以及对昇腾 NPU 
等国产硬件的深度适配，力求在 B 端 API 竞争中实现最低的 Token 
成本。

5.  **Agent 的长程化与交织化 (Interleaved Agent)**：
    内部正在研发 **Interleaved Agent** 和 **World-Play Agent** 
[12, 13, 
39]。目标是让智能体能处理极长周期的复杂任务，并能自发地与虚拟环境
（星野/Talkie）进行深度交互，而非简单的对话回复。
