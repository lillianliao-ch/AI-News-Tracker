# Skills 分析与研究库 (Skills Research)

这个目录专门用于存放评估、调研各种“AI Skills”、“开源工具”或“自动化库”的研究报告。

在这里，我们记录这些工具的**核心原理、局限性、对我们业务（如 AI猎头、学术挖掘、多模态聚合）的战略价值以及可能的业务场景**。

## 目录规范
- 每一个调研的工具对应一个单独的 `.md` 调研报告。
- 文件命名规范：`工具名_research.md`（例如：`notebooklm_py_research.md`）。
- **注意区分**：这里是**“调研报告库”**。如果你最终决定让本地 Agent（如 Claude Code）正式跑某个 Skill，那个 Skill 的执行脚本和统一说明（`SKILL.md`）应该被安装到你的 `.agent/skills/` 目录下。
